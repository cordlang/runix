# Templates Runix

Apps escritas en **Cordlang 1.0** (`.cord`). Runix no añade keywords.

| Id | Uso |
|----|-----|
| `starter` | Sitio de dos rutas + layout + counter |
| `landing` | Una ruta, hero de producto |

```bash
npx @cordlang/runix init mi-sitio
npx @cordlang/runix init landing-demo --template landing
```
